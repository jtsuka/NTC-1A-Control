## 1. 目的

Ver0.6.0.3 の画面構造・髭チャート・Manual表示・リスク判定・sticky列・表示サイズ切替などの既存機能を維持したまま、次の表示改善を行う。

1. kintone標準絞り込みを母集団条件として尊重する。
2. JavaScript内部の固定条件 `納期 >= 今日` を廃止する。
3. 表示軸は今日から過去90日まで保持し、左スクロールで過去日程を確認できるようにする。
4. 初回表示時は今日付近を表示する。
5. 外注先切替、30/60/90日切替、表示サイズ切替などの画面内再描画では、閲覧中の横スクロール位置を維持する。
6. 連続操作時に古い遅延処理が最新描画を上書きしないよう、描画世代番号でガードする。

## 4. 標準絞り込み優先

レコード母集団は `kintone.app.getQueryCondition()` で取得したkintone標準一覧の絞り込み条件を使用する。

Ver0.6.0.3に存在したJavaScript内部の固定条件:

`納期 >= 今日`

は削除する。

追加してよい条件はページング等の技術条件のみとする。

- `$id > lastId`
- `order by $id asc`
- `limit 500`

「今日以降のみ」を初期一覧条件にしたい場合は、JavaScriptに隠し条件を追加せず、kintone標準一覧の保存済み絞り込み条件で設定する。

## 5. 日付表示範囲

内部表示軸:

- 左端: 今日 - 90日
- 基準: 今日
- 右端: 今日 + 選択日数 - 1

既存の30日 / 60日 / 90日切替は維持する。

過去90日より古いレコードが標準絞り込み結果に含まれていても、表示軸を自動的に過去方向へ無制限拡張しない。

## 6. 初回スクロール

初回表示、または標準一覧条件により母集団を再取得した直後は、上段・下段をそれぞれ今日付近まで横スクロールする。

対象スクロール領域:

- 上段: ヒートマップ自身を含む `.eh-table-scroll`
- 下段: `.eh-schedule-scroll`

上段については、同クラスを使う別表を誤取得しないよう、`.eh-heatmap` から最寄りの `.eh-table-scroll` を取得する。

## 7. 画面内再描画時のスクロール保持

外注先クリック、30/60/90日切替、表示サイズ切替等では、毎回今日へ戻さない。

処理方針:

1. 再描画前に上段・下段それぞれの `scrollLeft` を退避する。
2. `root.innerHTML` 再生成後、新しいスクロール要素へ退避値を復元する。
3. ユーザーが過去日程を見ている途中でも、その位置を維持する。

これにより、外注先を切り替えた際に今日へ強制的に戻る挙動を防ぐ。

## 8. 遅延処理の世代番号ガード

スクロール調整は描画確定後に実行するため、`requestAnimationFrame` と遅延処理を使用する。

高速な連続クリック等では、前の描画で予約した遅延処理が後から実行され、最新のスクロール位置を古い値で上書きする可能性がある。

そのため描画ごとに世代番号を進める。

概念:

```javascript
state.renderGeneration = (state.renderGeneration || 0) + 1;
const myGeneration = state.renderGeneration;
```

遅延実行時:

```javascript
if (state.renderGeneration !== myGeneration) return;
```

これにより、最新世代以外の遅延スクロール処理は無効化する。
