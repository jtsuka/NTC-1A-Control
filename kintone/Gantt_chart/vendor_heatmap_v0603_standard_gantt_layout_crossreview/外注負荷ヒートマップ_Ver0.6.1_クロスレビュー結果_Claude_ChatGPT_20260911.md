## 2. 実コードで確認できた事項

### F1. JS固定 `納期 >= 今日` の除去

基準実装 `fetchActiveRecords()` に、標準一覧条件とは別に固定の `納期 >= 今日` 条件が存在する。
Ver0.6.1ではこれを削除し、業務母集団は `kintone.app.getQueryCondition()` の標準絞り込み条件のみとする。

JSが追加してよいのは `$id > lastId`、`order by $id asc`、`limit 500` 等の技術的ページング条件のみ。

### F2. viewStart の過去90日拡張

基準実装 `render()` の日付範囲は、上段ヒートマップと下段ガントの双方へ共通して渡されている。

したがって、

- `viewStart = today - 90日`
- `viewEnd = today + rangeDays - 1日`

とすることで、上段・下段の基準日付範囲を同一に保ったまま拡張可能。

### F3. 初期今日位置 — 条件を具体化

基準実装では横スクロールコンテナが別々に存在する。

- 上段ヒートマップ: `.eh-table-scroll`
- 下段ガント: `.eh-schedule-scroll`

よって、初期表示を今日位置にするには、**描画完了後に両方へ個別に `scrollLeft` を設定することを必須条件とする。**

片方だけ今日位置に移動し、もう片方が90日前の先頭に残る状態は T02 FAIL とする。

初期位置設定では以下を確認する。

1. 上段 `.eh-table-scroll` が今日付近から始まる
2. 下段 `.eh-schedule-scroll` が今日付近から始まる
3. sticky列分の左幅を考慮して今日列が隠れない
4. kintone描画後に位置が0へ戻らない
5. Chrome実機で確認する

### F4. 髭チャートへの非干渉

基準実装の `clippedCellSpan()` / `cellSpanStyle()` は `viewStart` からの相対日数で位置を決定しており、日付の絶対値に依存する特殊分岐はない。

そのため、`viewStart` を90日前へ拡張するだけで既存髭描画を流用できる見込みが高い。

**以下は変更禁止:** 

- `renderVendorDetail()` の髭構造
- 左ヒゲ / 太線 / 右ヒゲ生成ロジック
- ○ / ▶ / ● / ◆ マーカー
- `clippedCellSpan()`
- `cellSpanStyle()`
- 既存ガント行HTML構造

### F5. sticky列

上段・下段のsticky列の `left` は固定列幅に基づき、日数 `totalDays` には依存しないため、viewStartの過去拡張による直接影響は小さいと判断する。

### F6. 標準絞り込み + `$id` ページング

既存 `v0.5.9.1` 系のクエリ構築を維持し、固定today条件だけを除去する方針であればリスクは低い。

## 3. 実装条件

Ver0.6.1実装は、**Ver0.6.0.3を完全コピーした新ファイルを母体**として行う。

変更範囲を以下に限定する。

1. `CONFIG` に `pastDays: 90` を追加
2. `fetchActiveRecords()` の固定 `納期 >= 今日` 条件を削除
3. `render()` の `viewStart` を `today - 90日` に変更
4. 既存 `viewEnd` の30/60/90日切替を維持
5. 描画完了後、上段 `.eh-table-scroll` と下段 `.eh-schedule-scroll` の**両方**を今日位置へ移動
6. 必要に応じて既存headerへ小さな「今日へ戻る」ボタンを追加

**上記以外の機能再設計は禁止。**

## 4. T02 改訂版 — 初期表示位置

### 操作

1. Ver0.6.1をロード
2. 表示期間60日で一覧を開く

### PASS条件

- 上段 `.eh-table-scroll` が今日付近から表示される
- 下段 `.eh-schedule-scroll` が今日付近から表示される
- 両方とも90日前の左端から開始しない
- 今日列または今日付近の日付がsticky列に隠れない

- 上段または下段のどちらか一方でも90日前から始まる
- 初期位置設定後に描画タイミングで `scrollLeft=0` 相当へ戻る
- sticky列により今日列が実質見えない
- 髭チャートや既存レイアウトを壊して初期位置を実現している
