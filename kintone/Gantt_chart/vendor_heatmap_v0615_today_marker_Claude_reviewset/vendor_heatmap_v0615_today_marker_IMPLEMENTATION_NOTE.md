## 目的

## 変更内容
- `renderHeatmap()` 内でブラウザローカル日付を `startOfDay(new Date())` から取得。
- 既存の `formatDate()` と同じ形式で比較し、今日の日付ヘッダへ `eh-today-column eh-today-header` を付与。
- 今日の負荷セルへ `eh-today-column` を付与。
- CSSの疑似要素で2pxの縦基準線を重ねる。
- 今日のヘッダ文字のみ太字・文字色で強調。
- 赤/黄/緑の負荷背景色、土日背景、列幅、高さは変更しない。
