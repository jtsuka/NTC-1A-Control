# Format-KonyuCSV_RFC 改修仕様書
## 4桁年統一＋手配書番号なし行の除外オプション追加
### 2026-09-20

**母体:** アップロードいただいた現行 `Format-KonyuCSV_RFC.ps1`（2桁年出力・列ずれ補正・RFC 4180出力）
**変更方針:** 既存ロジック（読込・列ずれ補正・トリム・RFC出力・CP932処理）は変更しない。
以下2点だけを追加・変更する。

---

## 1. 変更点①：出力日付を4桁年に統一

### 1.1 理由

kintone公式ヘルプ（レコード登録・上書き用のファイルの記載形式）が案内する日付形式は、

```text
YYYY-MM-DD（4桁年＋ハイフン）
YYYY/MM/DD（4桁年＋スラッシュ）
YY/MM/DD（2桁年＋スラッシュ）
```

等であり、**「2桁年＋ハイフン」（旧スクリプトの出力形式）は公式一覧に無い組み合わせ**である。
旧kintoneアプリで読み込めていたのは事実だが、これはkintone側のパーサーが公式ドキュメントより
寛容だったためと考えられ、正式にサポートされた形式ではない。

したがって、公式に明記されている`YYYY-MM-DD`形式へ統一する。

### 1.2 変更内容

出力時の日付フォーマット文字列を変更する。

```text
変更前: $parsed.ToString("yy-MM-dd")
変更後: $parsed.ToString("yyyy-MM-dd")
```

入力側の日付解釈（`yyyy/M/d H:mm`等、購買部門CSVは常に4桁年で来る前提）は変更しない。

---

## 2. 変更点②：手配書番号が空欄の行を除外するオプション

### 2.1 背景

JOINを外した形でデータが来た場合、「手配書番号」列が空欄になる行が混在することが
2026-09-20の調査で判明した。この空欄行を、外注課ガントチャートへの取込対象から
除外したい、という要求。

### 2.2 仕様

新規スイッチパラメータ `-ExcludeMissingOrderNo` を追加する。

```text
指定なし（既定）: 従来通り、手配書番号の有無に関わらず全行を出力する。
指定あり        : 「手配書番号」列が空欄（前後スペース除去後に空文字）の行を、
                  出力対象から除外する。
```

**既定では何も変わらない。** 明示的にスイッチを指定したときだけ除外が有効になる。

### 2.3 対象列の特定

ヘッダー行から「手配書番号」という列名を検索し、その列インデックスを使う
（既存の日付列判定・列ずれ補正で使っている手法と同じ、ヘッダー名によるインデックス解決）。

`-ExcludeMissingOrderNo` 指定時に「手配書番号」列がヘッダーに存在しない場合は、
即座にエラー停止する（除外しようにも対象列が無いという矛盾状態のため）。

### 2.4 除外の判定タイミング

列ずれ補正（`Repair-ColumnShift`）の**後**、日付変換・トリム処理と同じ行内ループの中で判定する。
理由：列ずれ補正前の生の列位置では、行によって手配書番号の実際の位置がずれている可能性があるため、
補正後の正しい列位置で判定する必要がある。

除外された行は出力に追加せず、除外件数をカウントして完了時にログへ表示する。

### 2.5 完了ログへの追加

```text
既存: ヘッダー列数 / 処理行数 / 列ずれ補正 / 日付変換 / スペーストリム / 出力先
追加: 手配書番号なし除外（-ExcludeMissingOrderNoオプション指定時のみ表示）
```

---

## 3. 変更しないもの

- CP932読込・CP932/BOMなし出力
- 列ずれ補正ロジック（`Repair-ColumnShift`）自体の中身
- RFC 4180準拠の全項目クォート出力
- 文字列トリム（前後スペース・全角スペース）
- 日付列の判定方法（ヘッダー名による`$DateColumns`照合）
- 入力側の日付解釈フォーマット一覧

---

## 4. 使用方法

```powershell
# 従来通り（除外オプションなし）
.\Format-KonyuCSV_RFC_yyyyMMdd_OrderNoFilter_v1.ps1 `
    -InputPath "外注課納期管理_購買部門.csv" `
    -OutputPath "外注課納期管理_整形済み.csv"

# 手配書番号なし行を除外する場合
.\Format-KonyuCSV_RFC_yyyyMMdd_OrderNoFilter_v1.ps1 `
    -InputPath "外注課納期管理_購買部門.csv" `
    -OutputPath "外注課納期管理_整形済み.csv" `
    -ExcludeMissingOrderNo
```

---

## 5. テスト項目

- T01 通常CSV・除外オプションなし: 全行がそのまま出力される（従来と同じ動作）
- T02 通常CSV・除外オプションあり・手配書番号が全行にある: 除外0件、全行出力
- T03 手配書番号が空欄の行を含むCSV・除外オプションあり: 空欄行だけが除外され、
      除外件数がログに表示される
- T04 手配書番号が空欄の行を含むCSV・除外オプションなし: 空欄行も含めて全行出力される
      （既定動作が変わっていないことの確認）
- T05 「手配書番号」列自体が存在しないCSV・除外オプションあり: エラー停止する
- T06 日付変換結果が4桁年（`yyyy-MM-dd`）になっていることを確認
- T07 列ずれ補正が発生する行で、補正後の正しい列位置を見て除外判定していることを確認
      （商品名・商品情報の列ずれで手配書番号の位置がずれるケース）
