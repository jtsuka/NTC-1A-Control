# v3.0.3 / Rev.3.5 変更メモ

## 変更理由
既存レコードでは、追加フィールドの初期値が過去データへ遡及しないため、
`K暫定設定` と `K日程種別` が空欄のものが存在した。
v3.0.2では厳密一致判定のため、これらが暫定ON/OFFの対象外になっていた。

## Rev.3.5の扱い
- `K暫定設定` 空欄 → OFF相当
- `K日程種別` 空欄 → Auto相当
- Manualは従来どおり完全保護

### 暫定ON
選択外注先の Auto または空欄日程種別を対象に日程計算し、
更新成功時に
- `K暫定設定 = ON`
- `K日程種別 = Auto`
へ正規化する。

### 暫定OFF
選択外注先の Auto または空欄日程種別を対象に
- `K加工着手日 = 手配日`
- `K完成検査日 = 納期`
へ戻し、
- `K暫定設定 = OFF`
- `K日程種別 = Auto`
へ正規化する。

これにより、既存空欄データは運用の中で自然に正規値へ移行する。
