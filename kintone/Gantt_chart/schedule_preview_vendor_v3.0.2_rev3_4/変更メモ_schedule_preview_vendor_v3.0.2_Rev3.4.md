# v3.0.2 / Rev.3.4 変更メモ

## 今回の修正

暫定OFFの仕様を「K日付を空欄にする」方式から、現在の運用意図に合わせて
**基準日程へ戻す方式**へ変更した。

### 暫定OFF対象
- 選択した外注先
- `K日程種別 = Auto`

### 暫定OFF処理
- `K加工着手日 = 手配日`
- `K完成検査日 = 納期`

### 保護
- `K日程種別 = Manual` は一切変更しない
- 他外注先は変更しない
- 手配日または納期が未設定なら更新せず集計する

旧v2.1のような全件復元には戻していない。
**「選択外注先＋Auto限定」**というRev.3系の安全条件は維持する。

Manual自動検知（edit.show / edit.submit比較）、外注先別の検／着、
K暫定設定=ONによる暫定ON対象制御は変更していない。
