# TC106 Bridge Project

## 概要
製糸工場の Nittenser テンションコントローラシステム (TC-102/TC106) の
メインコントローラ (NTC-1A) を Raspberry Pi + ESP32-S3 で代替する個人プロジェクト。

## システム階層
- メインコントローラ NTC-1A (PIC16F73)
- 中継基板 (ハブユニット、6 錘ぶら下がり、デイジーチェーン)
- テンションユニット TC-102/TC106 (dsPIC33FJ16MC102)

## 追加調査 (R4 の特定)

### 実物写真による確認

中継基板の R4 を実物写真で確認した結果、カラーコードは:

**茶 - 赤 - 黒 - 赤 - 茶/金**

→ **R4 = 12 kΩ** (5バンド精密金属皮膜抵抗)

### MC34063 出力電圧の再計算
- Vout (無負荷) = 1.25V × (1 + 12k/1k) = 16.25V
- Vout (実用)   = 約 15.0V (オシロ実測)

MC34063 のロード時電圧ドロップ (-8% 程度) を考慮すると、計算値と実測値は完全に整合する。

### 回路図の修正必要箇所

| 部品 | 元の値 (回路図) | 修正値 (実物) |
|---|---|---|
| R4 | 6.2 kΩ | **12 kΩ** |

これは回路図起こし時の読み取り違いと判明。「青-赤-赤」(6.2k) と「茶-赤-黒」(12k) を視認で読み間違えた可能性が高い。

### 設計意図の推定

C3 = 470uF/16V を考えると、出力 15V (実用時) は耐圧ぎりぎりの設計。
Nitta の設計者は「**15V 動作前提の DC-DC**」として MC34063 を構成していたと判明。
