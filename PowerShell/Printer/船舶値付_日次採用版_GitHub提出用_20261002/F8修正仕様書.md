# 船舶値付PS版 F8日付互換補正仕様書

作成日：2026-10-02（日本時間）

対象PS1：Print-ValueTag_Ship_v0.10.10_P9FIX_CheckLogExt_Alignment_F8FIX_20261002.ps1

## 目的と基準

ユーザーが指定した「VBAの印字表現へ揃える」基準に従う。2026/10/02の注番E26A028130では、元CSVの124列（発注者1）が「2月9日」、従来PSも「2月9日」、VBAの最終印字は「2/9/2026」だった。VBAのCSV読込はWorkbooks.Openで、データ辞書へセルValueを登録する。Excelの型変換が原因候補。元CSVと原典VBAは変更せず、PSの表示値を補正する。

母体は全24ページの実印刷で検証済みの縦原点補正版（before-F8.ps1）。HardMarginYを縦移動量から引く修正とprint-metrics.jsonlは保持する。

## 実装仕様

Build-Override内で、target_cellがF8、かつsource_field_idが124のときだけ変換する。従来から行われていたTrimとExcelエラー文字列の除外後に適用する。

対象文字列は全体がASCII数字1～2桁の「月」「日」に一致するものに限定する。

```text
^(?<Month>[0-9]{1,2})月(?<Day>[0-9]{1,2})日$
```

実行開始時点のDateTime.Now.Yearを基準年として一度取得する。有効な月日ならDateTimeを作り、InvariantCultureのM/d/yyyyで文字列化する。年はCSVファイル名・更新日時から推測せず、VBAがCSVを読み込む実行年に対応させる。

| 入力・条件 | 出力 |
|---|---|
| F8／124、2月9日、2026年実行 | 2/9/2026 |
| F8／124、02月09日、2026年実行 | 2/9/2026 |
| F8／124、2月29日、2024年実行 | 2/29/2024 |
| F8／124、2月29日、2026年実行 | 入力を維持 |
| F8／124、人名や文字列 | 入力を維持 |
| F7／124、2月9日 | 入力を維持 |
| F8／125、2月9日 | 入力を維持 |

不正な日付、年を明記した日付、スラッシュ区切り、全角数字、前後に文字が付いたものはこの補正の対象外。汎用DateTime.Parseを使わず、他セルへの日付推測を追加しない。特定の注番や「2月9日」だけをハードコードしない。

変換したときだけ、注番・基準年・変更前後をコンソールへ診断出力する。CSV・VBA・業務の集計や選別・警告優先順位は変更しない。

## 検証

Test-F8Compatibility.ps1は候補PSのASTから2関数だけを取り出して実行する。スクリプト全体をdot-sourceしないため、単体テストで印刷を開始しない。20ケースで有効日、境界値、うるう年、不正日付、通常文字列、年の違い、対象セル／フィールドの制限を検証し全件PASS。

同じ当日CSV・設定で全24注文をプレビュー再実行。MaxOrders=24を明示して既存プレビューの自動15件制限を避けた。24ページ・1,381ログ行を処理し、変更前後のデータキーと値を比較。値の変更はE26A028130のF8の1件のみ（2月9日→2/9/2026）。他の値・注文・明細の対応に変更なし。プレビューの座標は印刷座標とは違うため、値・キーの比較に使い、位置の合格証明には使わない。

実印刷の結果は別添の再テスト結果.md／final-test-result.jsonを根拠とする。実印刷結果が未収録の場合、印刷検証は未完了であり、完了を推測しない。

## 使用・復元

Windows PowerShell 5.1と既存のconfig JSONが必要。実印刷はPrinterNameをDocuWorks Printerに指定する。既存の設定をコピーして独立した試験フォルダーで動かす。日次タスクは従来版のままで切り替えていない。

before-F8.ps1は直前の縦原点修正版。original-20260929.ps1はその母体。復元は起動対象を退避版へ戻す。今回、現行ファイルを置換していないため現行運用を元へ戻す操作は不要。

## 適用限界

本修正は観測した日本語の年なし月日形式を再現する限定修正。全てのExcel地域設定やCSV自動型推定を再現するものではない。実機VBAで直接観測済みなのは今回の「2月9日」の2026年表現であり、他の境界ケースはDateTime変換の単体テストで、Excelへの入力試験ではない。日時の設定が異なるPCや翌年の過去CSV再実行は別途確認が必要。

円記号20件、印字内容の自動確認未確定251項目、固定項目の最終印字認定は別課題。F8が一致しても、全印字内容の完全一致や本採用を自動的に宣言しない。
