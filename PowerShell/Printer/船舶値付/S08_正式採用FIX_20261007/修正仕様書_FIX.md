# 原典調査と粗利率ゼロ修正仕様

2026-10-07。対象はE26A046290、PS19ページの1明細目V12。

原典VBA Process.MakeDataの1187行付近で、請求先単価と営業原価単価が正の場合に粗利率を計算する。PrintableShapesの1855行付近には「数値が0は表示しない」と明記し、値が0ならCONTINUE_3へ進んでBODYへの書込みを飛ばす。従って粗利率計算結果が厳密に0のとき空欄になるのは原典の明示した処理である。

PSはV12を再計算して、結果が0でも0.0%を描画していた。今回の修正は同じ再計算ブロックで結果が0のときだけV12へ明示的な空文字を設定する。非ゼロは従来どおりN1形式で表示する。小さい非ゼロ値の丸め表示0.0%を一律で非表示にはしない。特定注番、CSV粗利率列233、価格2100のハードコードは使わない。

単体8ケースPASS。等価単価・正利益・負利益・微小非ゼロ・単価ゼロ・負の単価を確認した。当日24注文の前後プレビューを同じ条件で比較し、V12の0.0%のキー1件だけが消え、残り1476件の値・キー・座標・幅・高さは全て不変だった。

候補作成・再テストの時点では日次版と原典を変更していない。その後、ユーザー指示で日次配置を更新した。before.ps1に元版を保持し、manifest.jsonへ元版・候補・入力のSHA256を記録。06:32にユーザーが実行し、今日の全24ページをDocuWorksへ出力。新XDWの回収元／先ハッシュ一致を確認し、全24ページを600dpi白黒で比較した。23ページは全画素同一、19ページの全差分はV12内だけ。拡大画像でVBAと同じ空欄を確認し、残り1476ログはすべて不変。今回の粗利率ゼロ補正はPASS、仕様FIX。
