## 第2版 r2 からの修正（第3版 r3）
全角・半角カナを含む文字列の描画を、原典（Excel）の文字送り幅に合わせた。
- 従来のPSは全角文字が原典より約10%広く、欄いっぱいの長い文字列の端が欠けていた（例：発注先「…関西営業部大阪2G」の「2G」）。
- 全角は1.0em、半角カナは0.507emの固定送り幅で1文字ずつ描画（実測：原典VBA出力の文字位置）。em（文字の大きさ）はフォントの設計情報から、描画先Graphicsの単位で求める。
- 並べた全体の幅が欄の幅を超える場合は、欄に収まるよう横幅だけを縮めて描画し、文字が欠けないようにする。
- 差分は `差分_r2_to_r3.diff`（改行コードを無視して作成）。

## 使い方
スクリプトと `config\` を同じフォルダに置き、Windows PowerShell 5.1 で実行する。
```
powershell -NoProfile -ExecutionPolicy Bypass -File Print-ValueTag_Ship_20261014_LayoutFix_r3.ps1 -CsvPath <未計上明細_218001_YYYYMMDD.csv> -ConfigDir .\config -PrinterName "DocuWorks Printer" -MaxOrders 0
```
本番フォルダには印刷スクリプト（`Print-ValueTag*.ps1`）を1本だけ置く。
