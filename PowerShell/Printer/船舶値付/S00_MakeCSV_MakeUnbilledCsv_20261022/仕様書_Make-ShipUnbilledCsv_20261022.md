## 3. 行の抽出
I列（`最終出荷日`、既定 `-FilterColumn 9`）が前営業日（`yyyyMMdd`）と等しい行。比較はExcel風の値変換後の値で行う（Excelのフィルターは変換後の値に対して働くため）。見出し行は常に残す。該当0件なら見出しのみのCSVを作り、終了コード30。

## 4. 前営業日と休日判定
**運用方針（2026-10-22 ユーザー指定）：カレンダー（休日判定・前営業日）は、これまでどおりRK-10で行う。** RK-10が休日ならシナリオを終了し、平日なら当日と前営業日の文字列を本スクリプトへ渡す。この場合、スクリプトはカレンダーを読まない。

```
-NoProfile -ExecutionPolicy Bypass -File "<場所>\Make-ShipUnbilledCsv.ps1" -Date "{当日}" -PrevBusinessDay "{前営業日文字列}"
```

以下は、`-PrevBusinessDay` を渡さない場合の予備機能（単独で試験・運用するとき用）。カレンダーの式（`前営業日` シート）を再現する。
- 前営業日 = `WORKDAY.INTL(今日, -1, 1, 休日!A:A)`（土日と休日リストの日を飛ばして1営業日戻る）。
- 休日判定 = `COUNTIF(休日!A:A, 今日) > 0`（リストにあれば休日）。土日は、リストに載っているときだけ休日。
- Excelを使わず、xlsxをZIPとして読む（Excelが開いていても読める）。Excelの`TODAY()`のキャッシュ値は使わない。
- `-PrevBusinessDay` で前営業日を直接指定、`-SkipHolidayCheck` で休日でも作成（試験用）。

## 5. Excelの値の変換（再現する規則）
RK-10はCSVを一度Excelで開いて保存するため、値が変わる。次の規則で再現する（文字列の前後の空白は、数値として読めるときだけ除かれる）。

| 元の値 | 変換後 | 例 |
|---|---|---|
| 数値として読める（先頭0・末尾空白・小数の先頭の0なし を含む） | 数値の標準表記 | `00`→`0`、`1000152    `→`1000152`、`.54`→`0.54`、`065`→`65` |
| 整数部が11桁超など | 指数表記 | `123456789012`→`1.23457E+11` |
| `yy-mm-dd`／`yyyy/mm/dd`（日付） | `yyyy/m/d` | `26-10-14`→`2026/10/14` |
| 日付＋時刻 | `yyyy/m/d h:mm`（秒は落ちる） | `2026/10/19 08:52:56`→`2026/10/19 8:52` |
| `m-d`（月日） | `m月d日` | `2-9`→`2月9日`、`1-10`→`1月10日` |
| `h:mm(:ss)` | 時刻 | `08:30`→`8:30` |
| 円記号付きの数 | 通貨表記（推定） | `\2.200`→`\2.20` |
| `true`/`false` | 大文字 | `TRUE` |
| 上記以外 | そのまま（前後の空白も保つ） | `WIN999B2   ` |

2桁の年は 00〜29→2000年代、30〜99→1900年代。引用符は、`,` `"` 改行を含む値にだけ付ける（Excelと同じ）。「=」で始まる値はExcelでは数式になるため、変換せず警告ログに件数を出す。
