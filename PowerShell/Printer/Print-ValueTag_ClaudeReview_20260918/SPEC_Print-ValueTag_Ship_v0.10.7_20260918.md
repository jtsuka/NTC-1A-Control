## 2. 原典・目的

原典は Excel VBA `@(自動)企画室 船舶値付用紙出力.xlsm`。
目的は、Excel/VBA依存を外し、PowerShell 5.1 + GDI+ / PrintDocument で夜間無人運転できるようにすること。

業務互換条件は、内部実装をVBAと同じにすることではなく、次の業務結果を一致させること。

- 対象手配集合
- 各手配の明細集合
- HEAD / BODY表示値
- 警告表示
- Gray8
- 複数ページ構成
- バーコード内容
- 印刷先
- 自由記述原文保持
- 正常／異常終了判定

VBA固有の「1手配=1PrintOut → DocuWorksで後から束ねる」工程と、その偶然の最終ページ順は互換条件から外す。

## 3. 船舶モードの主要条件

- 工場番号: `FAC11`
- 対象受注番号: `E` 始まり
- 手配内に未検収明細が1件でもあれば、その手配を印刷対象とする
- 検収済みBODY明細だけ Gray8
- 全明細検収済みなら手配全体を印刷しない
- Y受注金額注意、原価未入力、売価未入力、締め日fallback等は原典VBAに合わせる
- BJ12は設定由来値を一旦除去し、警告 → 数量>1時の製造原価合計の優先順で最終値を決める

## 4. v0.10.7 の変更点

v0.10.6からの変更は A7「標準表示」のみ。

DL列192「商談状況」を以下に変換する。

- `6` → `標準`
- `1` → `後報`
- `0` / 空欄 / その他 → 空欄

A7以外の抽出、BODY、改ページ、船舶ロジックには変更を加えない。

## 7. RK-10との責務境界

RK-10:

- 基幹操作
- 対象日の決定
- CSV取得・配置
- CSVフルパスをPSへ渡す
- PS終了コード確認

PowerShell:

- `-CsvPath` で渡されたCSVのみ処理
- 最新CSVを自動探索しない
- 対象日を独自再計算しない
- 対象抽出
- 帳票生成
- 印刷ジョブ投入
- ログ / 終了コード
