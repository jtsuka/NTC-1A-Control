## 4. 購買抽出仕様（BT_NO=3原典準拠）

- 工場番号: `FAC11`
- 受注番号先頭: `T / E / L / H`

### 在庫抜き

`OUT_OF_STOCK=1`

次の得意先番号を除外:

- `1000012` 札幌在庫
- `3000010` 仙台在庫
- `5000017` 東京在庫
- `7000014` 福岡在庫
- `11000010` 大阪在庫
- `15000015` 船舶在庫

### 担当手配抜き

`OUT_OF_PERSON=1`

得意先番号の文字数が6以下の行を除外する。

### 最終出荷日下限

`START_DATE = Year(Date)-3 & "1216"`

2026年は `20231216`。これより古い最終出荷日の行を除外する。

### 送料無料運賃行除外

- 品目番号=`99999900`
- 特記事項1または特記事項2に `送料無料`

の行を除外する。

### 手配単位 kou / genka

`kou=1`:

- 同一手配内に `品目番号 Like "KOU*"`
- かつ `品目番号 <> "KOU000"`
- の明細が1件以上

`genka=1`:

- 同一手配内に `品目番号 <> COMENT`
- `仮単価区分 = 仮`
- `営業原価_単価 = 0`
- の明細が1件以上

最終対象:

`kou = 1 AND genka = 1`

kouとgenkaは同じ明細で成立する必要はなく、手配単位の存在フラグ。
全明細検収済み手配は印刷対象外。

## 6. v0.2.1 のA7修正

A7はDL列192「商談状況」を元にする表示専用セル。

- `6` → `標準`
- `1` → `後報`
- `0` / 空欄 / その他 → 空欄

v0.2で実PDF上、生値`0`が残った例:

- `T266091720`
- `T268083190`

v0.2.1ではA7のみ局所修正し、他の抽出・ページング・帳票ロジックは変更しない。

## 7. 自由記述の原文保持

特記事項・商品情報などの自由記述は、先頭が `=` / `+` / `-` / `@` 等でも業務文字列としてそのまま扱う。
Excel式として評価しない。

代表ケース:

```text
@206.000+緊急対応費15.000
=221.000 SKﾃｯｸ福嶋氏打合せ分
```

原本CSVを処理継続目的で削除・置換・無害化しない。

2026-09-18実機回帰では `T268083190` の先頭`=`を保持した原本CSVで正常完走し、帳票上も先頭`=`付きで出力された。
