# FIX11 最小修正仕様書 — 2CSV Baseline Site Guard

対象: `ProcessSheetRows r15.10 REV5.1 2CSV`
日付: 2026-09-29
状態: REVIEW CANDIDATE / 未本番投入
前提: FIX10は凍結済み

## 1. 目的
2CSV Baselineを「Initializedという1ビット」ではなく、**どの拠点のBaselineかまで含む正式状態**として判定する。

ワークブックコピー、誤配置、テストコピー流用などで、別拠点のBaseline markerを信用してPhase1/Phase3を開始する事故を防ぐ。

## 2. 正本メタ情報
History sheet `新規商品コード登録履歴` の K1:L3:

```text
K1 BaselineStatus          | L1 Initialized
K2 BaselineInitializedAt   | L2 date/time
K3 BaselineInitializedSite | L3 SiteName
```

`BaselineInitialized=True` の必要十分条件:
1. 上記ラベル/valueが正式形式
2. timestampが空でない
3. L3が空でない
4. L3 == current SiteName（case-insensitive）

## 3. FIX11-01 Get-NewProductHistoryState
引数追加:
`ExpectedSiteName`

追加返却:
- `BaselineMetadataValid`

## 4. FIX11-02 2CSV fail-closed rules
DatasetCount=2かつHistory sheetが存在する場合:

### Legacy J1-only marker
J1=`BASELINE_INITIALIZED` だがK1:L3正式メタなし:
- 自動信用しない
- 自動migrationしない
- 新商品機能をERROR/SKIP
- 手動確認を要求

### Site mismatch
正式メタは成立するがL3 != current SiteName:
- fail-closed
- Phase1/Phase3を行わない

### History rows without formal metadata
CandidateKey rowsがあるのに正式メタがない:
- 自動Baseline Initializeを許可しない
- fail-closed
- 手動確認を要求

理由: stale/partial/copied Historyを現在拠点のBaselineとして上書き確定しないため。

## 5. FIX11-03 Set-NewProductBaselineInitialized
必須引数:
- Workbook
- SheetName
- SiteName

動作:
- SiteName空欄はthrow
- J1 legacy markerは空欄化
- K1:L3正式メタを書込
- 文字列COM書込は `NumberFormat="@"` + `[string]Value2`
- timestampはdouble OADate + date format

### Rollback safety
J1を残さない。
これによりFIX11からFIX10以前へロールバックした場合、旧コードはBaselineを勝手にTrueと認識せず、安全側Falseになる。

## 6. FIX11-04 Baseline candidates = 0
設計上、Baseline候補0件でもInitializedは成立可能。

現行コードでは候補0件だと`Write-NewProductHistoryRows`がHistory sheetを作らず、Set側がmetadata-only sheetを作る可能性がある。
その後Registered行が来るとA:Iヘッダー無しHistoryになる潜在欠落がある。

FIX11ではSet側がHistory sheetを新規作成した場合のみ、A:IヘッダーもFIX9-safe patternで作る。

## 7. FIX11-05 post-write verification
Baseline Initialize write直後、Save前に同一SiteNameでHistory stateを再読込。

必須:
- BaselineMetadataValid=True
- BaselineSiteMatch=True
- BaselineInitialized=True

不成立ならthrowし、既存catch/Close(false)契約でSaveしない。
